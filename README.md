# Food Delivery Time Predictor

## Problem Statement
Predict the delivery time of a food order in minutes.

## Input Features
- distance_km
- prep_time_min
- traffic_level
- rain

## Target
- delivery_min

## Problem Type
Regression

## Evaluation Metric
Mean Absolute Error (MAE)

## Project Status

Initial machine learning models have been trained and evaluated using MAE and RMSE.
